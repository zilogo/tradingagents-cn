## 2. 技术栈

### 2.1 前端

| 组件 | 技术 | 版本 |
|------|------|------|
| 框架 | Vue 3 | 3.x |
| 构建工具 | Vite | 5.x |
| UI组件库 | Ant Design Vue | 4.x |
| 图表库 | ECharts | 5.x |
| 状态管理 | Pinia | 2.x |
| 路由 | Vue Router | 4.x |
| HTTP客户端 | Axios | 1.x |
| 国际化 | Vue I18n | 9.x |

### 2.2 后端

| 组件 | 技术 | 版本 |
|------|------|------|
| Web框架 | FastAPI | 0.100+ |
| 异步运行时 | Uvicorn | 0.23+ |
| 任务调度 | APScheduler | 3.x |
| 数据验证 | Pydantic | 2.x |
| JWT认证 | PyJWT | 2.x |
| 密码哈希 | Passlib | 1.7+ |

### 2.3 数据存储

| 组件 | 技术 | 用途 |
|------|------|------|
| 主数据库 | MongoDB | 持久化存储 |
| 缓存 | Redis | 缓存/队列/会话 |

### 2.4 AI/ML

| 组件 | 技术 | 用途 |
|------|------|------|
| LLM框架 | LangChain/LangGraph | Agent编排 |
| 向量存储 | - | (预留) |

## 6. 安全架构

### 6.1 认证与授权

- JWT Token 认证 (1小时过期)
- Refresh Token (7天过期)
- 基于角色的访问控制 (RBAC)
- API 频率限制

### 6.2 数据安全

- HTTPS 传输加密
- 敏感数据加密存储 (API Keys)
- 密码 bcrypt 哈希
- 审计日志

### 6.3 API 安全

- CORS 配置
- 请求ID追踪
- 输入验证 (Pydantic)
- SQL/NoSQL 注入防护
